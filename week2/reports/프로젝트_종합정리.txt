---------------------------------------------------------------
 0. 한 줄로 말하면
---------------------------------------------------------------
"내일 원유 가격이 크게 출렁일지를 미리 알려주는 서비스"입니다.

전쟁·분쟁 같은 국제 뉴스 긴장도(GPR)와
주식시장 공포 분위기(VIX)를 보면
다음날 유가가 크게 움직일지 어느 정도 예측이 가능합니다.

같은 예측 모델을 두 가지 모드로 나눠서 제공합니다.
  · "위험 경보" 모드 : 조금만 이상해도 알림 (보험처럼)
  · "매수 타이밍" 모드 : 확실할 때만 알림 (찬스처럼)


===============================================================
 1. 왜 XGBoost 모델을 썼나?
===============================================================

[여러 모델을 직접 비교해봤습니다]
다섯 가지 예측 방법을 동일한 조건에서 경쟁시켰습니다.
  1) 랜덤 포레스트 (여러 개의 판단 트리를 모아 투표)
  2) 로지스틱 회귀 (가장 단순한 확률 계산)
  3) SVM (경계선을 그어서 구분)
  4) XGBoost (이번에 선택된 방법)
  5) KNN (가까운 사례들을 참고)

[결과: XGBoost가 1등]
"급변동을 얼마나 잘 잡아내는가(재현율)" 지표에서
XGBoost가 가장 높은 점수를 받았습니다.

[XGBoost가 좋았던 이유를 쉽게 말하면]

  1) "여러 변수의 조합"을 잘 읽어냅니다.
     예: VIX가 높을 때 + GPR도 오르는 날 → 위험
         이런 '조건 조합'을 스스로 찾아냅니다.

  2) "놓친 문제를 집중 복습"합니다.
     한 번 예측에 실패한 날짜가 있으면
     다음 학습 때 그 날을 더 신경 써서 다시 공부합니다.
     → 결과적으로 '급변동을 놓치지 않는' 능력이 좋아집니다.

  3) 한쪽으로 치우친 데이터도 잘 다룹니다.
     우리 데이터는 "평범한 날"이 64%, "급변동 날"이 36%로
     평범한 날이 더 많습니다. 이런 불균형을 보정하는
     옵션이 잘 마련되어 있습니다.

  4) 빠릅니다.
     매일 새로운 데이터로 다시 학습해야 해서 속도가 중요한데
     XGBoost는 대용량 처리에 최적화되어 있습니다.


===============================================================
 2. 어떤 정보(입력)를 모델에 넣었나?
===============================================================

총 7가지 지표를 매일 수집해서 넣고 있습니다.

  ┌──────────────────┬──────────────────────────────────────┐
  │ 지표              │ 쉽게 말하면                            │
  ├──────────────────┼──────────────────────────────────────┤
  │ VIX               │ "주식시장 공포 지수"                    │
  │                   │  투자자들이 얼마나 불안해하는지 숫자로 표시   │
  │ GPR 지수           │ "국제 긴장도"                          │
  │                   │  전쟁·테러·정치 불안 기사를 분석해서 점수화   │
  │ GPR 실제행동       │  실제로 충돌·테러가 일어난 정도           │
  │ GPR 위협          │  위협·경고성 사건 정도                   │
  │ 금 수익률          │  금값이 하루 사이 얼마나 움직였는지          │
  │ 천연가스 수익률     │  천연가스값이 하루 사이 얼마나 움직였는지     │
  │ 은 수익률          │  은값이 하루 사이 얼마나 움직였는지          │
  └──────────────────┴──────────────────────────────────────┘

[왜 이 지표들을 골랐나?]

  · VIX : 시장 분위기가 '오늘 당장' 얼마나 불안한지
  · GPR : 정치·지정학적으로 '중장기 구조적' 불안
    → 두 지표는 성격이 달라서 서로 보완해줍니다.

  · 금/은/천연가스 : 원유와 함께 움직이는 '형제 자산'들
    → 원유만 보지 않고 주변 시장도 같이 봅니다.

[왜 원유 자체 과거 가격은 안 썼나?]
"내일 원유가 어떻게 될지"를 예측하는 게 목적인데,
어제 원유 가격을 많이 쓰면 모델이 "어제 오른 날은 오늘도 오른다"
같은 단순 규칙에 의존하게 됩니다.
그래서 일부러 '바깥 지표들만' 사용했습니다.

[데이터 기간]
2020년 1월 3일 ~ 2026년 4월 22일 (총 1583일치)


===============================================================
 3. 어떤 결과(출력)를 보여주나?
===============================================================

두 가지를 동시에 예측합니다.

[예측 A — 급변동 확률]
  "내일 원유 가격이 하루 사이 ±2% 이상 움직일 확률"
  예시: 47.5% → 절반 가까운 확률로 크게 움직일 수 있음

  ※ 왜 "2%"가 기준인가?
  지난 6년간 일일 변동 통계를 보면
  하루에 ±2% 이상 움직인 날이 전체의 약 36%였습니다.
  이 정도 변동은 뉴스에도 보도되는 "유가 급등/급락" 수준입니다.

[예측 B — 방향과 수익률]
  "내일 오를지 내릴지"와 "대략 몇 % 움직일지"
  예시: 상승 +1.11% → 내일 소폭 오를 것으로 예측

[화면에 보여지는 방식]

  위험 경보 모드                    매수 타이밍 모드
  ──────────────                    ──────────────
  급변동 가능성 47.5%                47.5%
  기준선: 30% 넘으면 알림             기준선: 70% 넘으면 알림
  → "오늘 시장을 주시하세요"           → "신호 대기 중"
  예측 방향: 상승 +1.11%              예측 방향: 상승 +1.11%


===============================================================
 4. 성능은 어떻게 측정했나?
===============================================================

[어떻게 채점했나 — "과거로 미래 맞히기" 방식]

모델의 실력을 공정하게 평가하려면
"과거 데이터로 학습 → 이후 데이터로 시험"을 해야 합니다.

  ┌─────────────────────────────────────────────────────┐
  │ 1차 시험: 2020~2021년 공부 → 2021~2022년 맞히기        │
  │ 2차 시험: 2020~2022년 공부 → 2022~2023년 맞히기        │
  │ 3차 시험: 2020~2023년 공부 → 2023~2024년 맞히기        │
  │ 4차 시험: 2020~2024년 공부 → 2024~2025년 맞히기        │
  │ 5차 시험: 2020~2025년 공부 → 2025~2026년 맞히기        │
  └─────────────────────────────────────────────────────┘

이 5번의 시험 성적을 평균 내서 최종 점수로 사용합니다.
(이걸 "시계열 교차검증"이라고 부릅니다)

[점수표]

  ┌───────────────┬────────┬───────────────────────────┐
  │ 지표             │ 점수    │ 뜻                         │
  ├───────────────┼────────┼───────────────────────────┤
  │ 전체 정확도        │ 61.3%  │ 10번 예측 중 6번 맞힘          │
  │ 경보 신뢰도        │ 41.2%  │ 알림이 울리면 10번 중 4번은 진짜 │
  │ 급변동 포착률 ★    │ 33.6%  │ 실제 급변동 10번 중 3~4번 잡음 │
  │ 종합 점수 (F1)    │ 35.8%  │ 위 두 지표의 균형값           │
  └───────────────┴────────┴───────────────────────────┘

[왜 '급변동 포착률'이 제일 중요한가]
이 서비스는 "놓치면 손해"가 핵심입니다.

  · 경보를 울렸는데 아무 일 없었다 → 사용자가 조금 긴장했을 뿐
  · 경보를 안 울렸는데 급변동이 왔다 → 실제로 돈을 잃음

두 실수의 무게가 다릅니다.
그래서 "놓치지 않는 능력"을 가장 중요한 지표로 삼았습니다.

[두 가지 모드 철학]
  · 위험 경보 모드 (30% 기준)
    → "애매해도 일단 알려주자"
  · 매수 타이밍 모드 (70% 기준)
    → "확실할 때만 알려주자"


===============================================================
 5. 이 서비스의 한계
===============================================================

솔직하게 어려운 부분도 공유합니다.

[1] 실제 급변동의 약 2/3는 아직 못 잡습니다.
    포착률 33.6% → 개선의 여지가 많습니다.
    특히 갑작스런 뉴스(예: 중동 공습, OPEC 긴급 발표)는
    VIX·GPR 지표가 '사후적으로' 반응해서
    예측이 어렵습니다.

[2] 쓰는 정보가 아직 적습니다.
    - 원유 재고량, 생산량 같은 수급 지표 없음
    - 미국 금리, 달러 가치 같은 거시 지표 없음
    - 뉴스 텍스트 자체 분석은 아직 안 함

[3] 시대가 변하면 예전 패턴이 안 통합니다.
    2020년(코로나)과 2022년(러-우전쟁) 때의 시장은
    2024~2026년과 성격이 달라서
    모델이 최신 시장에 100% 적응하지 못한 부분이 있습니다.

[4] '2%'라는 급변동 기준이 고정입니다.
    변동성이 큰 시기에는 2% 넘는 날이 너무 많고
    조용한 시기에는 2%를 넘는 날이 거의 없어서
    시기에 따라 모델의 학습 균형이 달라집니다.

[5] 수익률 예측 숫자는 참고용입니다.
    방향(상승/하락)과 확률(급변동 가능성)은 참고할 만하지만
    "+1.11% 정확히 오를 것"같은 숫자는
    실제보다 보수적으로 예측되는 경향이 있습니다.
    → 사이트에도 "수익률은 참고용" 안내 문구를 넣었습니다.

[6] 주말·공휴일엔 업데이트 안 됩니다.
    미국 선물시장이 쉬는 날은 새 데이터가 안 올라옵니다.

[7] 외부 데이터 제공처에 의존합니다.
    야후 파이낸스나 GPR 사이트가 장애 나면
    그날 갱신이 실패할 수 있습니다.


===============================================================
 6. 앞으로 어떻게 발전시킬까?
===============================================================

[가장 먼저 할 것 — 정보를 더 다양하게]

  1) 변화·추세 지표 추가
     - 'VIX가 어제보다 얼마나 뛰었는지' (변화율)
     - 'GPR 최근 일주일 평균' (추세)
     - 원유 변동성 자체 (최근 5일간 얼마나 흔들렸는지)

  2) 경제 상황 지표 추가
     - 달러 가치 지수
     - 미국 국채 금리
     - 미국 주간 원유 재고 발표치

  3) 달력 정보 추가
     - 요일 (월요일/금요일은 패턴 다름)
     - 미국 금리 결정 회의 주간 여부
     - OPEC 회의 임박 여부

[그다음 — 모델 자체 개선]

  4) 자동 최적화 튜닝
     수십 가지 설정값 조합을 자동으로 시도해서
     최고의 조합을 찾아냅니다.
     → 포착률 33.6%에서 45% 이상으로 올릴 목표

  5) 기준선(알림 임계값) 최적화
     지금은 "30% / 70%"를 감으로 정한 느낌인데
     데이터로 "딱 최적인 값"을 찾아 바꿀 예정입니다.

  6) 여러 모델 합치기 (앙상블)
     XGBoost 혼자가 아니라
     비슷한 다른 모델들의 의견도 모아서 종합 판단.

[장기 계획 — 서비스 확장]

  7) 자동 재학습 파이프라인
     매일 새 데이터로 모델을 다시 공부시키는 과정을
     완전 자동화.

  8) 알림 채널 확대
     카카오톡·이메일·디스코드로도 경보 수신.

  9) 뉴스 분석 기능
     실시간 뉴스 기사를 AI가 읽고
     "이 기사는 유가에 부정적" 같은 판단을 추가.

 10) 다른 원자재로 확장
     금·천연가스·은 각각에 맞춤 모델을 만들어 같이 제공.


===============================================================
 7. 누구한테 쓸모있는 서비스인가? (타겟 고객)
===============================================================

하나의 기술을 두 가지 모드로 제공해서
정반대 성향의 고객 모두 만족시킵니다.

  ┌────────────┬──────────────────────┬──────────────────────┐
  │             │ 🛡 위험 경보 모드       │ 🎯 매수 타이밍 모드    │
  ├────────────┼──────────────────────┼──────────────────────┤
  │ 기준        │ 30% 넘으면 알림        │ 70% 넘으면 알림       │
  │ 성격        │ 민감 · 자주 알림        │ 신중 · 확실할 때만    │
  │ 우선순위    │ 놓치지 않기             │ 헛발질 안 하기        │
  └────────────┴──────────────────────┴──────────────────────┘

[개인 고객 (B2C)]

  ▶ 위험 경보 모드가 어울리는 분들
    · 원유 ETF(코덱스 원유선물 등) 보유한 개인 투자자
    · 주유소·운수업·배달업 하시는 소상공인
      → 유가가 크게 오르면 수익에 바로 타격
    · 투자 초보자
      → "내가 모르는 사이 일이 터지면 어쩌지" 걱정 해소

  ▶ 매수 타이밍 모드가 어울리는 분들
    · 적극적인 개인 트레이더 (원유 선물·CFD)
    · 레버리지 상품 이용자
      → 한 번 잘못 들어가면 손실 커서 '확실할 때만' 선호

[기업 고객 (B2B)]

  ▶ 위험 경보 모드가 어울리는 기업
    · 정유사·항공사·해운사 리스크 관리팀
      → 연료비 급등 대비 헷지 타이밍 결정
    · 에너지 많이 쓰는 제조업 (철강·석유화학·발전소)
    · 보험사 원자재 익스포져 부서
    · 공공기관 (에너지공단, 석유공사)의 정책 모니터링

  ▶ 매수 타이밍 모드가 어울리는 기업
    · 자산운용사 원자재 펀드 매니저
    · 헷지펀드 트레이딩 데스크
    · 은행 원자재 거래부서
    · 원자재 트레이딩 전문 회사

[왜 이 서비스가 차별화되는가]

  1) 같은 모델, 두 가지 철학
     → 복잡한 AI 지식 없어도 "내 상황에 맞는 모드" 하나만 고르면 됨

  2) 어려운 용어 대신 일상 언어
     → '정밀도·재현율' 대신 '위험 경보·매수 타이밍'
     → 퍼센트 막대와 색깔로 직관적 표현

  3) 솔직한 성능 공개
     → 모델 성능 지표 페이지에서 혼동행렬·교차검증 결과 그대로 공개
     → "이 정도 실력입니다" 숨기지 않음

  4) 무료 공개
     → 로그인 없이, 설치 없이, 모바일·PC 어디서든 접속
